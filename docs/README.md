# Beginner's guide to the EEG project

Start with [Understanding `inspect_dataset.py`](inspect_dataset.md).

That guide explains the inspection script from the ground up: the dataset files, Python syntax, each function, execution order, terminal output, and limitations of the checks.

You can read the `.md` files directly or open them in your editor's Markdown preview. In VS Code, open a file and use **Open Preview** from the Command Palette.

The guide describes the current source code. It does not require you to run the EEG processing pipeline.
